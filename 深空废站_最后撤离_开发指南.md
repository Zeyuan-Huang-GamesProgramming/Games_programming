# 《深空废站：最后撤离》Unity 小白实操版（从 0 到可玩）

> 这版是“照着做就能跑”的教程：**每个脚本写什么、放哪、在 Unity 里点哪里** 都写清楚。

---

## 0) 你将做出什么（最终效果）

- WASD 移动 + 鼠标看视角。
- 按 `E` 和门、终端交互。
- 终端任务共 3 个，全部完成后撤离舱可用。
- 氧气会持续下降，降到 0 就失败。
- HUD 显示：氧气、剩余时间、任务进度、提示文本。

- 给 `Player` 添加：
  - `CharacterController`

  - `PlayerOxygen`
- 把 `Main Camera` 拖到 `Player` 下作为子物体。

### 2.2 交互物体设置

- `Door_A` 添加 `BoxCollider`（默认即可）和 `DoorController`。

- `EscapePod` 添加 `BoxCollider` 和 `EscapePod`（脚本）。

## 3.2 `Assets/Scripts/Player/PlayerController.cs`

```csharp
using UnityEngine;

[RequireComponent(typeof(CharacterController))]
public class PlayerController : MonoBehaviour
{
    public float moveSpeed = 4f;
    public float gravity = -9.81f;
    public float lookSensitivity = 2f;

    private CharacterController controller;
    private Transform cam;
    private float pitch = 0f;
    private Vector3 velocity;

    void Start()
    {
        controller = GetComponent<CharacterController>();
        cam = Camera.main.transform;
        Cursor.lockState = CursorLockMode.Locked;
    }

    void Update()
    {
        // 鼠标视角
        float mouseX = Input.GetAxis("Mouse X") * lookSensitivity;
        float mouseY = Input.GetAxis("Mouse Y") * lookSensitivity;

        transform.Rotate(Vector3.up * mouseX);
        pitch -= mouseY;
        pitch = Mathf.Clamp(pitch, -75f, 75f);
        cam.localRotation = Quaternion.Euler(pitch, 0f, 0f);

        // 移动
        float x = Input.GetAxis("Horizontal");
        float z = Input.GetAxis("Vertical");
        Vector3 move = transform.right * x + transform.forward * z;
        controller.Move(move * moveSpeed * Time.deltaTime);

        // 重力
        if (controller.isGrounded && velocity.y < 0)
            velocity.y = -2f;

        velocity.y += gravity * Time.deltaTime;
        controller.Move(velocity * Time.deltaTime);
    }
}
```

## 3.3 `Assets/Scripts/Player/PlayerOxygen.cs`

```csharp
using UnityEngine;

public class PlayerOxygen : MonoBehaviour
{
    public float maxOxygen = 180f;
    public float currentOxygen;
    public float consumePerSecond = 1f;

    void Start()
    {
        currentOxygen = maxOxygen;
    }

    void Update()
    {
        currentOxygen -= consumePerSecond * Time.deltaTime;
        currentOxygen = Mathf.Clamp(currentOxygen, 0f, maxOxygen);

        if (currentOxygen <= 0f)
        {
            GameManager.Instance.GameOver("氧气耗尽，撤离失败");
        }
    }

    public void AddOxygen(float amount)
    {
        currentOxygen = Mathf.Clamp(currentOxygen + amount, 0f, maxOxygen);
    }
}
```

## 3.4 `Assets/Scripts/Player/InteractionHandler.cs`

```csharp
using UnityEngine;

public class InteractionHandler : MonoBehaviour
{
    public float interactDistance = 3f;

    void Update()
    {
        Ray ray = new Ray(Camera.main.transform.position, Camera.main.transform.forward);
        if (Physics.Raycast(ray, out RaycastHit hit, interactDistance))
        {
            IInteractable interactable = hit.collider.GetComponent<IInteractable>();
            if (interactable != null)
            {
                HUDController.Instance.SetHint(interactable.GetPrompt());

                if (Input.GetKeyDown(KeyCode.E))
                    interactable.Interact();

                return;
            }
        }

        HUDController.Instance.SetHint("");
    }
}
```

## 3.5 `Assets/Scripts/Core/GameManager.cs`

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

public class GameManager : MonoBehaviour
{
    public static GameManager Instance;

    public float totalTime = 720f;
    public float remainTime;

    public int totalTasks = 3;
    public int completedTasks = 0;

    public bool gameEnded = false;

    void Awake()
    {
        if (Instance == null) Instance = this;
        else Destroy(gameObject);
    }

    void Start()
    {
        remainTime = totalTime;
    }

    void Update()
    {
        if (gameEnded) return;

        remainTime -= Time.deltaTime;
        if (remainTime <= 0f)
        {
            remainTime = 0f;
            GameOver("时间耗尽，撤离失败");
        }
    }

    public void CompleteTask()
    {
        completedTasks++;
        completedTasks = Mathf.Clamp(completedTasks, 0, totalTasks);
    }

    public bool AllTasksDone()
    {
        return completedTasks >= totalTasks;
    }

    public void WinGame()
    {
        if (gameEnded) return;
        gameEnded = true;
        HUDController.Instance.ShowCenterMessage("撤离成功！");
        Cursor.lockState = CursorLockMode.None;
    }

    public void GameOver(string reason)
    {
        if (gameEnded) return;
        gameEnded = true;
        HUDController.Instance.ShowCenterMessage(reason);
        Cursor.lockState = CursorLockMode.None;
    }

    public void Restart()
    {
        SceneManager.LoadScene(SceneManager.GetActiveScene().name);
    }
}
```

## 3.6 `Assets/Scripts/World/TerminalTask.cs`

```csharp
using UnityEngine;

public class TerminalTask : MonoBehaviour, IInteractable
{
    public string taskName = "修复终端";
    private bool done = false;

    public string GetPrompt()
    {
        return done ? "该终端已修复" : "按 E 执行任务: " + taskName;
    }

    public void Interact()
    {
        if (done) return;

        done = true;
        GameManager.Instance.CompleteTask();
        HUDController.Instance.ShowCenterMessage(taskName + " 完成");
    }
}
```

## 3.7 `Assets/Scripts/World/DoorController.cs`

```csharp
using UnityEngine;

public class DoorController : MonoBehaviour, IInteractable
{
    private bool opened = false;

    public string GetPrompt()
    {
        return opened ? "门已打开" : "按 E 打开门";
    }

    public void Interact()
    {
        if (opened) return;

        opened = true;
        transform.position += transform.right * 2f; // 简单“滑开”
    }
}
```

## 3.8 `Assets/Scripts/World/EscapePod.cs`

```csharp
using UnityEngine;

public class EscapePod : MonoBehaviour, IInteractable
{
    public string GetPrompt()
    {
        if (GameManager.Instance.AllTasksDone())
            return "按 E 撤离";

        return "任务未完成，无法撤离";
    }

    public void Interact()
    {
        if (!GameManager.Instance.AllTasksDone()) return;
        GameManager.Instance.WinGame();
    }
}
```

## 3.9 `Assets/Scripts/UI/HUDController.cs`

```csharp
using UnityEngine;
using UnityEngine.UI;

public class HUDController : MonoBehaviour
{
    public static HUDController Instance;

    public Text oxygenText;
    public Text timerText;
    public Text taskText;
    public Text hintText;
    public Text centerText;

    private PlayerOxygen oxygen;

    void Awake()
    {
        if (Instance == null) Instance = this;
        else Destroy(gameObject);
    }

    void Start()
    {
        oxygen = FindObjectOfType<PlayerOxygen>();
        centerText.text = "";
    }

    void Update()
    {
        if (oxygen != null)
            oxygenText.text = $"氧气: {oxygen.currentOxygen:0}";

        if (GameManager.Instance != null)
        {
            timerText.text = $"时间: {GameManager.Instance.remainTime:0}";
            taskText.text = $"任务: {GameManager.Instance.completedTasks}/{GameManager.Instance.totalTasks}";
        }
    }

    public void SetHint(string msg)
    {
        hintText.text = msg;
    }

    public void ShowCenterMessage(string msg)
    {
        centerText.text = msg;
    }
}
```

## 9) 常见报错与解决

1. `NullReferenceException` 多半是 UI 引用没拖。
2. `Camera.main` 为空：确认 Main Camera 标签是 `MainCamera`。
3. 按 E 没反应：确认交互物体有 Collider，且挂了实现 `IInteractable` 的脚本。
4. 角色穿地：地面需要 Collider（Cube 默认有）。
