# Free Asset Store Options

These resources are listed as free on the official Unity Asset Store. Downloading and importing them requires confirmation of the applicable licenses through your own Unity or Asset Store account.

## Recommended Resources

1. Stylized Astronaut
   - Use: Replace the current basic-model astronaut.
   - Link: https://assetstore.unity.com/packages/3d/characters/humanoids/sci-fi/stylized-astronaut-114298

2. Sci-Fi Styled Modular Pack
   - Use: Replace basic wall, floor, and door-frame geometry.
   - Link: https://assetstore.unity.com/packages/3d/environments/sci-fi/sci-fi-styled-modular-pack-82913

3. Modular Sci-Fi Corridor
   - Use: Build a more detailed space station corridor environment.
   - Link: https://assetstore.unity.com/packages/3d/environments/sci-fi/modular-sci-fi-corridor-142811

4. Space Station Free 3D Asset
   - Use: Add an exterior space-station model or background display.
   - Link: https://assetstore.unity.com/packages/3d/vehicles/space/space-station-free-3d-asset-hdrp-urp-built-in-188734
   - Note: This package is large, approximately 1.8 GB.

5. Planet Earth Free
   - Use: Add an Earth visual or an exterior space backdrop.
   - Link: https://assetstore.unity.com/packages/3d/environments/sci-fi/planet-earth-free-23399

## Import Instructions

1. Open Unity.
2. Sign in with your Unity Hub or Unity Editor account.
3. Open the Asset Store page and select `Add to My Assets`.
4. Return to Unity and open Package Manager.
5. Select `My Assets`.
6. Locate the resource, select `Download`, and then select `Import`.
7. Drag imported prefabs into the scene to replace the existing basic models progressively.

## Current Built-In Substitute Content

Before external assets are imported, the scene builder generates the following content from Unity basic geometry:

- Astronaut player appearance
- Illuminated space station corridors
- Repair terminals
- Escape pod
- Oxygen canisters
- Hazard areas and mission signs

After free assets are imported, these basic models can be replaced with the imported art assets.
