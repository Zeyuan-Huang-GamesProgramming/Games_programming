# 免费 Asset Store 资源建议

这些资源来自官方 Unity Asset Store，价格显示为 FREE。下载和导入需要使用你自己的 Unity/Asset Store 账号确认许可证。

## 推荐资源

1. Stylized Astronaut
   - 用途：替换当前基础模型宇航员
   - 链接：https://assetstore.unity.com/packages/3d/characters/humanoids/sci-fi/stylized-astronaut-114298

2. Sci-Fi Styled Modular Pack
   - 用途：替换当前基础方块墙体、地板、门框
   - 链接：https://assetstore.unity.com/packages/3d/environments/sci-fi/sci-fi-styled-modular-pack-82913

3. Modular Sci-Fi Corridor
   - 用途：搭建更真实的空间站走廊
   - 链接：https://assetstore.unity.com/packages/3d/environments/sci-fi/modular-sci-fi-corridor-142811

4. Space Station Free 3D Asset
   - 用途：外部空间站模型或背景展示
   - 链接：https://assetstore.unity.com/packages/3d/vehicles/space/space-station-free-3d-asset-hdrp-urp-built-in-188734
   - 注意：文件较大，约 1.8 GB。

5. Planet Earth Free
   - 用途：窗外太空背景或地球视觉
   - 链接：https://assetstore.unity.com/packages/3d/environments/sci-fi/planet-earth-free-23399

## 导入方法

1. 打开 Unity。
2. 登录 Unity Hub / Unity Editor 的账号。
3. 打开 Asset Store 页面，点击 Add to My Assets。
4. 回到 Unity，打开 Package Manager。
5. 选择 My Assets。
6. 找到资源，点击 Download，然后 Import。
7. 导入后可以把资源里的 Prefab 拖入场景，逐步替换当前的基础模型。

## 当前项目已经做的替代方案

在没有导入外部资源前，当前场景生成器会用 Unity 基础几何体生成：

- 宇航员玩家外观
- 发光空间站走廊
- 维修终端
- 撤离舱
- 氧气罐
- 危险区和任务提示牌

等你导入免费资源后，可以继续把这些基础模型替换成真实资源。
