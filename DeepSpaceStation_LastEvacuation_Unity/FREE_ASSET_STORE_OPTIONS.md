# Free Unity Asset Store Options

This note records free Unity Asset Store resources that were considered during
development. The availability, price, and licence terms of Asset Store packages
can change, so the publisher page and Unity Asset Store terms should be checked
again before using or redistributing any package.

## Candidate Resources

1. **Stylized Astronaut**
   - Possible use: replace the simple placeholder astronaut/player visual.
   - Link: <https://assetstore.unity.com/packages/3d/characters/humanoids/sci-fi/stylized-astronaut-114298>

2. **SCI-FI Styled Modular Pack**
   - Possible use: corridor walls, floors, doors, frames, panels, and modular
     station architecture.
   - Link: <https://assetstore.unity.com/packages/3d/environments/sci-fi/sci-fi-styled-modular-pack-82913>

3. **Modular Sci-Fi Corridor**
   - Possible use: more detailed corridor modules and station environment
     dressing.
   - Link: <https://assetstore.unity.com/packages/3d/environments/sci-fi/modular-sci-fi-corridor-142811>

4. **Space Station Free 3D Asset**
   - Possible use: exterior station model or background presentation.
   - Link: <https://assetstore.unity.com/packages/3d/vehicles/space/space-station-free-3d-asset-hdrp-urp-built-in-188734>
   - Note: the package may be large and may require a suitable render pipeline.

5. **Planet Earth Free**
   - Possible use: background planet view outside station windows.
   - Link: <https://assetstore.unity.com/packages/3d/environments/sci-fi/planet-earth-free-23399>

## Import Method

1. Open Unity and sign in with a Unity account.
2. Open the Asset Store page and add the asset to My Assets.
3. Return to Unity and open Package Manager.
4. Select My Assets.
5. Download and import only the files needed for the project.
6. Record the package name, publisher, URL, and licence notes in
   `THIRD_PARTY_ASSETS.md`.

## Project Use

The current project already uses imported science-fiction environment resources

audio integration, testing notes, and project documentation remain project work
